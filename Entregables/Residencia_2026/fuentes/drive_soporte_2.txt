Edge Computing
(Local)
SQLite guarda datos y coordenadas GPS cuando no 
hay red. Sin pérdida de información.
Cloud Computing
(Nube)
Google Sheets API + Google Drive API para 
centralización de datos y expedientes.
Frontend Mobile
.NET MAUI
C# + XAML para despliegue multiplataforma. APK 
listo para equipos Android de operadores.
Sincronización Asíncrona Inteligente
