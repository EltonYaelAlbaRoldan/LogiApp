Hardware requerido
• Dispositivo Móvil Android (Smartphone): Es el hardware principal de operación. 
Debe contar con sensor GPS integrado y conectividad (WiFi/Datos móviles) para la 
recolección de telemetría en ruta.
• Computadora de Desarrollo (PC/Laptop): Estación de trabajo con procesador de 
arquitectura x64, necesaria para la compilación, depuración y despliegue del código 
fuente mediante el entorno de desarrollo.
• Servidores en la Nube (Google Cloud Infrastructure): Infraestructura remota que 
aloja la base de datos centralizada y el sistema de gestión de archivos (DMS), 
eliminando la necesidad de servidores físicos locales en TLB Transportes.
Software requerido
• .NET MAUI Framework: Framework multiplataforma utilizado para construir la interfaz 
de usuario (UI) nativa y la lógica de negocio de la aplicación móvil.
• SQLite (Engine local): Motor de base de datos relacional ligero insertado en la app, 
encargado de la persistencia de datos en escenarios de "Ceguera de Red" (Edge 
Computing).
• Google Sheets & Drive APIs: Interfaces de programación de aplicaciones que 
permiten la comunicación asíncrona entre el dispositivo móvil y la nube para el reporte 
de viajes y evidencias.
• Visual Studio 2022 (Community Edition): Entorno de Desarrollo Integrado (IDE) 
utilizado para la codificación en lenguaje C# y XAML.
Competencias (Habilidades)
• Desarrollo de Aplicaciones Móviles: Conocimientos avanzados en el ciclo de vida de 
apps móviles y manejo de sensores de hardware (GPS).
• Arquitectura de Software Híbrida (Edge-to-Cloud): Capacidad para diseñar sistemas 
que procesan datos localmente (Edge) y se sincronizan de forma inteligente con la nube 
(Cloud).
• Integración de APIs y Seguridad: Implementación de protocolos de autenticación 
segura (OAuth 2.0) y consumo de servicios web RESTful.
• Gestión de Bases de Datos: Habilidad para estructurar modelos de datos relacionales 
tanto en entornos locales (SQLite) como en hojas de cálculo escalables (Sheets).
